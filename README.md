# 學測國寫 111～115 考前快速複習

111～115 學年度學測國語文寫作能力測驗歷屆題導向考前快速複習網站。

## 使用方式

年度快速複習 → 5～10 分鐘 → 關閉網站 → 90 分鐘模擬考。

## 線上版

GitHub Pages 的發布來源為 `main / docs`。目前 remote 尚未設定，不填寫或猜測 GitHub Pages URL；本 repo 目前只完成可發布的本地 release build。

## 離線版

下載 `release/國寫學測111-115_完整離線包.zip`，解壓後直接開啟 `國寫學測111-115_離線版.html`。

## 內容

- 111～115 歷屆題快速複習
- 五年總整理
- 第一大題 80 字短答
- 第一大題 400 字知性寫作
- 第二大題情意寫作
- 官方評分原則整理
- 高分策略與常見失分
- 答題卷提醒

## 內容定位

不是作文百科。本網站只保留考前真正值得看的內容；教材內容以專案內官方 PDF 核對結果為準。
